# Security policy

## Supported version

Security fixes are applied to the current `main` branch and latest tagged release.

## Reporting

Do not include private medical information, credentials or confidential datasets in an issue. This application performs no server-side processing and intentionally sends no biological data to a backend.

For ordinary defects, open a GitHub issue. For a security-sensitive report, use GitHub's private vulnerability reporting feature when enabled for the repository.

## Scientific safety boundary

Scientific disagreement, model limitations and incorrect interpretation should use the **Scientific model review** issue template rather than a security report. The application is not intended for diagnosis, treatment selection or patient-specific prediction.
